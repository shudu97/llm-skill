# HTML Dashboard Skill

This skill describes how to:
1. Call the `data-visualization` subagent to generate ECharts figures
2. Extract the `<echarts-option>` block from the subagent response
3. Assemble text blocks and chart options into the intermediate JSON file
4. Call Bash to render the intermediate JSON into the final HTML dashboard

Full skill content is maintained on the enterprise machine at the equivalent
`.claude/skills/html-dashboard/` path and should be copied here to activate.
